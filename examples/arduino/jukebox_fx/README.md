# Jukebox (FX)

All **21** catalog songs live in one FX data image and are streamed by the
compact decoder. No song bytes are held in PROGMEM.

The backend contract is pinned by
[`docs/fx/integration.md`](../../../docs/fx/integration.md) and the loop
extension in the [architecture decision](../../../research/fx/fx-architecture-decision.md).
The minimal consumer is [`examples/fx/music_graphics`](../../fx/music_graphics).
Every catalog song loops and its region is larger than the ring, so the image
uses streaming `0xC1` loops.

## Controls

| Button | Action |
| --- | --- |
| `UP` | Previous song (wraps, plays immediately) |
| `DOWN` | Next song (wraps, plays immediately) |
| `A` | Restart the selected song |
| `B` | Pause / resume playback |

The display shows the index, song name, folder, loop length and stream bytes,
plus `PLAYING` / `PAUSED` / `READY`. It redraws only when selection or status
changes.

## How it works

`setup()` calls `FX::begin(JUKEBOX_FX_DATA_PAGE)`. `atm_fx_compact_fetch` reads
data-section-relative offsets with `FX::readDataBytes`, and `loop()` services
the decoder after `FX::display()`. `UP`/`DOWN`/`A` re-arm the decoder with
`atm_fx_compact_play(offset, length)`; `B` toggles pause/resume.

The image is generated by `tools/music_authoring/fx_jukebox.py`, which builds
each catalog song with `tools/atm-music build --backend fx`, packs the streams
with `tools/fx_image`, and rewrites `jukebox_fx_songs.h`:

```sh
python3 tools/music_authoring/fx_jukebox.py \
    --out-dir build/fx-jukebox \
    --header examples/arduino/jukebox_fx/jukebox_fx_songs.h \
    --ring 64 --streaming-loops
```

The header is the only committed build artifact. The image, metadata and
per-song reports land under `build/fx-jukebox/`.

## Build

```sh
FLAGS="-DATM_FX_COMPACT_LOOP=1 -DATM_FX_COMPACT_RING=64"
arduino-cli compile --fqbn arduboy-homemade:avr:arduboy-fx --library . \
    --build-path build/fx-jukebox/avr --output-dir build/fx-jukebox/out \
    --build-property "compiler.cpp.extra_flags=$FLAGS" \
    --build-property "compiler.c.extra_flags=$FLAGS" \
    examples/arduino/jukebox_fx
```

`ATM_FX_COMPACT_RING=64` must match the generator's `--ring`. Add
`-DATM_FX_COMPACT_DIAG=1` for the one-shot `FXDIAG` report.

Measured with the 21-song image (`build/fx-jukebox/fxdata.bin`, 93,039 B, data
page 65,172): program **14,170 B**, static SRAM **1,512 B**. The scores live on
the FX chip.

## Run

```sh
~/code/arduboy/Ardens/build/Ardens.app/Contents/MacOS/Ardens \
    "file=$PWD/build/fx-jukebox/out/jukebox_fx.ino.hex" \
    "file=$PWD/build/fx-jukebox/fxdata.bin"
```
